Bikin PRD

Sistem ngoding pakai AI: ide mentah → PRD → spesifikasi fitur → task kecil → AI eksekusi satu per satu. Gratis, tanpa daftar, semua diproses di HP/browser kamu — tidak ada data yang dikirim ke server.

1 Ide2 PRD3 Spesifikasi4 Task5 Eksekusi

Langkah 1 — Ide aplikasi

Jawab 3 hal ini. Kalau masih kabur, jangan lanjut dulu.

Langkah 2 — Daftar fitur

Tulis fitur-fiturnya saja, satu per baris. Minimal 1 fitur.

Langkah 3 — Teknologi (kunci di awal)

Isi dulu nama aplikasi, user, masalah, solusi, dan minimal 1 fitur.

Hasil — tinggal salin ke AI coding agent

Urutan pakai: PRD dulu, lalu spesifikasi, lalu kerjakan task satu per satu. AGENTS.md disimpan di folder proyek.


    
    
  


  

    
7 Aturan Emas

    
    
      
  1. Satu tugas per perintah. Perintah borongan = hasil ngarang.
    2. 
      
  2. PRD dulu, kode belakangan. Nggak ada PRD, nggak ada ngoding.
    3. 
      
  3. Kunci teknologi di awal. Ganti stack di tengah jalan = mulai dari nol.
    4. 
      
  4. Acceptance criteria di tiap fitur. Tanpa ini, "jadi" tidak bisa dicek.
    5. 
      
  5. Tes tiap task. Bug kecil yang dibiarkan jadi bug besar 5 task kemudian.
    6. 
      
  6. Keputusan ditulis, bukan diingat. Yang cuma ada di chat akan hilang.
    7. 
      
  7. Review sebelum lanjut. Baca file apa yang diubah AI sebelum perintah berikutnya.
    8. 
    

    
Cara pakai hasil di atas: tempel PRD + AGENTS.md ke AI coding agent, lalu beri SATU task. Tes hasilnya, kalau jalan lanjut task berikutnya, kalau rusak perbaiki dulu. Tiap task selesai = simpan.
